# Architecture

The root of this folder is the live source mounted into n8n at `/files/heygen-workflow`. `video-broll-factory.js` scans `incoming/`, uses `video-control.csv` as the queue and retry tracker, transcribes speech with ElevenLabs, plans B-roll, builds captions, and renders through FFmpeg. `video-broll-factory-workflow.json` is the n8n wrapper. `processed/` contains checkpoints and final files. The current automated planner still has Gemini provider paths; see `AGENTS.md` before any run.

`local-media-catalog.js` gates stock choices with `approved-stock-ids.json` and `broll-assets/asset-map.json`. A fresh clone may add ignored, locally approved clips through `local-approved-stock-ids.json` and `broll-assets/local-asset-map.json`. `speech-duration-planner.js`, `render-mixed-broll.js`, and `caption-grammar.js` handle timing, compositing, and caption correction. `vector-retrieval-service.py` searches the local SigLIP2 index in `vector-index/` (1 frame per second, scored over 3-second windows); `vector-retrieval-client.js` builds phrase-based queries and applies the match floor, and `local-media-catalog.js` provides a keyword fallback when the service is down. `broll-fit-check.js` (Phase 2) checks the exact seconds of each planned video shot through the service's `/verify` endpoint and keeps, moves, swaps or drops it. `broll-review-sheet.js` writes a contact sheet and review list per job. Search results require editorial and rights review.

`publishing/` is a separate draft and approval workflow. Rendering does not authorize posting. `runtime/n8n/` contains Docker Compose and private runtime state. `Start-Heygen.ps1` starts the local vector service and n8n after the portable setup.

Captions use abbreviation-aware short cue generation from original word timestamps, then `caption-policy.js` / `caption-glossary.json` for contextual product spelling, punctuation normalization and conservative word/name/negation/numeric protection. `caption-grammar.js` requests correction in contextual chunks and preserves cue indices/times. Cache version 3 fingerprints the glossary as well as raw text and provider settings. See `docs/CAPTIONS.md` for behavior, limits and isolated verification; finished videos are not automatically repaired.

Git tracks code, catalogs, rules, and docs. `.gitignore` excludes credentials, live tracker state, runtime dependencies, licensed/private media, and generated output. `Bootstrap-From-Git.ps1` imports supplied media and starts a Docker-based clone runtime with optional CPU vector service from `runtime/clone/`; the older `Setup-Portable.ps1` uses the bundled runtime. Clone bootstrap has offline coverage; its Docker build/unattended provider path remain unverified. Existing Docker/n8n has executed a real manual Quality batch with ElevenLabs transcripts, prepared Codex captions/plans and the live factory gate/shared renderer. This does not establish a planner/proofreading API run; see current handoff/session evidence. `versions/` contains rollback snapshots; edit live root files, not snapshots.

Quality stops also write Elements search links and a per-job `Open-Envato-Links.cmd`/HTML page. `Collect-Envato-Downloads.ps1` collects only finished files matching an unambiguous moment; unrelated files stay in Downloads, and collection stops once all moments are covered. Downloads remain manual in the user’s browser. These search links are not reviewed exact asset selections.
